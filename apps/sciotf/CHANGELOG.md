## 1.0.0 (2026-08-16)

### Features

* **sciotf:** add --output path option
* **sciotf:** add advanced export command and chamfer control
* **sciotf:** add support for xor modded base character mappings
* **sciotf:** Adding sciotf app for rendering sci0/01 fonts as OTF fonts
* **sciotf:** allow aspect ratio setting of "1:1.2"
* **sciotf:** support padding individual glyphs

### Bug Fixes

* **scibud:** normalize aspect ratio option on font show
* **sciotf:** better scaling to get pixel-perfect no-anti-aliasing render for PX fonts
